使用帮助

这个工具解决三件事：数学符号难打、公式排版不整齐、贴到 Word/PPT 里变形。

① 找符号

左侧按分类排好了希腊字母、运算、关系、箭头、集合、微积分、矩阵、结构模板等。 记不住命令就直接在搜索框输入中文或英文，比如「积分」「偏导」「属于」「sigma」。

② 写公式

  • 点一个结构模板（分数、根号、矩阵、分段函数…）会自动插入骨架，光标落在第一个空格里，按 Tab 跳到下一个空格。
  • 先选中一段内容再点模板（如 \sqrt、\frac），选中内容会直接填进模板。
  • ✨ 智能转换：随手写的 lim x->0 sinx/x、sqrt(x^2+1)、1/2、×、α 等会被自动改写成规范 LaTeX。
  • 右边「公式库」内置了高等数学常用公式（极限定义、泰勒公式、重要极限、中值定理、格林公式…），点击即可载入再改。

③ 复制到别的地方

  • 复制 LaTeX：给 Typora / Obsidian / Markdown / Overleaf / 其它 LaTeX 环境用。
  • 复制 $…$ / $$…$$：直接粘进 Markdown 笔记。
  • 复制 MathML：粘进较新版本的 Word、WPS，会识别成可以继续编辑的公式。
  • 复制图片 / 导出 PNG、SVG：粘进 PPT、Word、微信、打印讲义都不变形；PNG 可选 2×/4×/8× 分辨率。

快捷键

  • Ctrl+Enter　立即渲染并复制 LaTeX
  • Tab / Shift+Tab　在模板的空格之间前后跳
  • Ctrl+Z / Ctrl+Y　撤销 / 重做
  • Esc　关闭本窗口

离线说明

排版引擎（MathJax）已经放在同目录的 lib/tex-mml-svg.js 里，完全离线可用， 不需要联网。只要别删掉 lib 文件夹就行。
